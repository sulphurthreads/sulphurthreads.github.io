Straight from the source

What a module looks like inside.

These are real, unedited excerpts from the SulphurUI tree. Modules, blocks, switches and settings are all small tables that the core shell runs, so the rules below are built into how the code is written.

SulphurInfoBar/Core/Bar.luaLua
SulphurUI.Modules.Register("infobar", {
  label = "Sulphur Info Bar",
  default = false,
  onEnable = function()
    I.SetActive(true)
    Build()
    Bar.Apply()
    frame:Show()
    I.Blocks.SyncAll("module enabled")
    Log("enabled", { blocks = I.Blocks.CountOn(), edge = I.Get("edge") })
  end,
  onDisable = function()
    if not I.IsActive() then return end
    I.SetActive(false)
    I.Blocks.SyncAll("module disabled")
    if frame then frame:Hide() end
    Log("disabled")
  end,
})

Every module is its own addon and joins the suite through one call. It defaults off, and switching it off releases what it built. That is rule 01 in code.

SulphurInfoBar/Core/Blocks.luaLua
local DURABILITY_FIRST, DURABILITY_LAST = 1, 18
I.Block({
  id = "durability", label = "Durability",
  events = { "UPDATE_INVENTORY_DURABILITY", "UPDATE_INVENTORY_ALERTS" },
  paint = function()
    local lowest = 100
    for slot = DURABILITY_FIRST, DURABILITY_LAST do
      local cur, max = GetInventoryItemDurability(slot)
      if cur and max and max > 0 then
        local pct = cur / max * 100
        if pct < lowest then lowest = pct end
      end
    end
    return string.format("Durability %d%%", math.floor(lowest))
  end,
})

A block is data: an id, the events that repaint it and a paint function. It registers those events only while it is switched on, and it has no timer.

SulphurQoL/Core/Features.luaLua
-- Sell junk, through Compat.SellJunk: one server call on live, a stepped bag
-- walk on 5.5.4 that stops the moment the merchant closes.
local lastJunk

Q.Feature({
  key = "autoSellJunk",
  events = { "MERCHANT_SHOW", "MERCHANT_CLOSED" },
  OnEvent = function(event)
    if event == "MERCHANT_CLOSED" then
      merchantOpen = false
      return
    end
    merchantOpen = true
    local branch, count = Compat.SellJunk(function()
      return merchantOpen and Q.IsApplied("autoSellJunk")
    end)
    lastJunk = string.format("%s, %s item(s)", branch, tostring(count or "unknown"))
    if count == 0 then
      Q.LogThrottled("autoSellJunk-none", "no junk to sell", { branch = branch })
      return
    end
    Log("junk sold", { branch = branch, items = count or "unknown" })
  end,
  describe = function() return "last visit: " .. (lastJunk or "none this session") end,
})

Sell junk is one server call on Retail and a bag walk on MoP that stops as soon as the merchant closes. Compat picks the path, and every sale is logged.

The bar every module clears

Light enough to leave on in a 25-man.

Every new module is reviewed against the same four rules before it ships.

01

Zero cost unless enabled

A switched-off feature registers no events and builds no frames. Hidden means unregistered, not just invisible.

02

Opt-in by default

New settings ship off, so an update never rearranges your screen without you asking.

03

Event-driven

No per-frame polling. A timer exists only while the text that needs it is actually on screen.

04

Taint-safe

Blizzard's protected frames are placed and hidden through secure drivers, never hooked, so no mystery errors mid-pull.
