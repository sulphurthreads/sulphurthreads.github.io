Sulphur GRA

The Guild Raid Assistant is the first and largest SulphurUI module: four shared, draggable anchor frames that other elements attach to (move one, everything on it moves together), a floating Console output box, Hero Plan, pre-raid and ready checks, BiS tracking, guild-bank sync and a full set of slash commands.

Part of SulphurUI v0.118.0 Wago CurseForge
Install

GRA ships inside SulphurUI.

Install SulphurUI from Wago or CurseForge (either desktop app keeps it updated), or unzip by hand so SulphurUI and SulphurGRA sit directly inside Interface\AddOns. On MoP Classic the suite is SulphurUI + Sulphur GRA. Full steps on the home page.

Reference

Commands

/shelp in game lists every command for every module, so you never have to alt-tab mid-raid.

CommandWhat it does
/suiOpens the main window on its Home tab — the front door to everything the suite does. /sulphurui is the same command spelled out.
/ssettingsJumps straight to Settings — the cogwheel at the bottom of the sidebar, where the theme and window size live. /sui settings does the same.
/sgridOpens the layout studio: drag every window to where you want it, type exact X and Y, toggle snapping. /sgrid home snaps them all back to their defaults.
/sgraOpens the GRA section of the sidebar. GRA is a heading above Hero Plan, BiS and Storage, so a bare /sgra lands on Hero Plan.
/sgra anchorShows all four anchor frames so you can click-and-drag each to wherever you want anchored content placed on screen.
/sgra hideHides the anchor frames again once you are happy with their placement. Positions are saved automatically and persist across sessions.
/shelpOpens the Help tab — the full in-game command reference for every part of the suite. /sgra help lands here too.
