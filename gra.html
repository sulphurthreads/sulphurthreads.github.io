SulphurUI

SulphurUI is one themed addon window (/sui) with a shared look, and optional modules you turn on as you need them. Sulphur GRA — the Guild Raid Assistant — is the first and largest of those modules: four shared, draggable anchor frames that other elements can attach to (move one, everything on it moves together), a floating Console output box, and a full set of / commands. This page covers the GRA module in detail.

Hosted on Wago & CurseForge Current version v0.117.0

Get it in-game

  1. Grab the latest release from Wago or CurseForge (either desktop app installs it and keeps it updated):
    WagoCurseForge

    Latest: v0.117.0

  2. If installing manually: unzip the download so you end up with a SulphurGRA folder directly inside your Interface\AddOns folder.
  3. If WoW is already running, log out to the character-select screen so it picks up the new addon, then make sure it's enabled in your AddOns list.

Commands

CommandWhat it does
/sui Opens the main window on its Welcome tab — the front door to everything the addon does. /sulphurui is the same command spelled out.
/ssettings Jumps straight to Settings — the cogwheel at the bottom of the sidebar, where the UI theme and window size live. /sui settings does the same thing.
/sgra anchor Shows all four anchor frames (small purple boxes) so you can click-and-drag each wherever you want anchored content placed on screen.
/sgra hide Hides the anchor frames again once you're happy with their placement. Position is saved automatically and persists across sessions — you only need to do this once.
/sgra Opens the GRA section of the sidebar. GRA is a heading above Hero Plan, BiS and Storage, so a bare /sgra lands on the first of those, Hero Plan. Use /sui for the addon's home tab.
/shelp Opens the Help tab — the full in-app command reference covering every part of the addon, without needing to alt-tab to this site mid-raid. /sgra help lands here too.
